# 📸 SnapScene App v0.2.0

**Transform your screenshots into comprehensive testing strategies with AI**

![Version](https://img.shields.io/badge/version-0.1.0-green.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

> SnapScene analyzes your application screenshots and automatically generates detailed testing scenarios using Google Gemini AI. Perfect for QA teams, developers, and testing professionals.

---

## 🚀 Getting Started

### What You Need

1. **Google Gemini API Key** (free) - [Get yours here](https://ai.google.dev/)
2. **Screenshots or images** of your application
3. **5 minutes** to set up

### First Time Setup

1. **Download and start** SnapScene
2. **Click the ⚙️ Settings button** in the top-right
3. **Enter your API key** in the settings
4. **Click "🧪 Test API Key"** to verify it works
5. **Save settings** - you're ready to go!

---

## 📖 How to Use SnapScene

### Basic Workflow

**1. Upload Your Screenshot** 📤
- **Drag & drop** your image onto the upload area
- **Or click** the upload area to browse files
- Supports: PNG, JPG, JPEG, WEBP

**2. Choose Your Test Type** 🔬
- **Functional Testing** - Features and workflows
- **UI Testing** - Interface and visual elements  
- **Performance Testing** - Speed and efficiency
- **Security Testing** - Vulnerabilities and access
- **Accessibility Testing** - WCAG compliance
- **Usability Testing** - User experience
- **Compatibility Testing** - Cross-browser/device
- **General Analysis** - Overall testing scenarios

**3. Select Detail Level** 📊
- **Basic** (5-10 scenarios) - Quick overview
- **Detailed** (10-20 scenarios) - Comprehensive analysis
- **Comprehensive** (20+ scenarios) - Complete coverage

**4. Analyze** 🔍
- **Click "Analyze Image"**
- **Wait 10-30 seconds** for AI processing
- **Review generated test scenarios**

**5. Use Your Results** 💡
- **Read the scenarios** directly in the app
- **Copy to clipboard** for pasting into your tools
- **Save as file** for documentation
- **Use in your testing workflow**

## 🛠️ Troubleshooting

### Common Issues

**❓ Settings button not working?**
- Restart the application
- Check if you have an internet connection
- Try clicking the button again

**❓ Can't upload images?**
- Make sure files are PNG, JPG, JPEG, or WEBP
- Check file size is under 10MB
- Try dragging files directly onto the upload area

**❓ Analysis fails?**
- Verify your API key in Settings
- Test your API key using the "Test API Key" button
- Check your internet connection
- Make sure the image is clear and readable

**❓ API key not working?**
- Get a fresh key from [Google AI Studio](https://ai.google.dev/)
- Make sure you've enabled the Gemini API
- Check for any usage limits or restrictions

**❓ Results not detailed enough?**
- Switch to "Comprehensive" detail level
- Try a more specific test type
- Use higher quality screenshots
- Analyze multiple views of the same feature
